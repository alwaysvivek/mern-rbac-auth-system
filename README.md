# MERN User Management System (RBAC)

A full-stack User Management System emphasizing clean architecture, Role-Based Access Control (RBAC), and a premium SaaS-style interface. Built for the Purple Merit Technologies Intern Assessment.

## 🚀 Key Features

### Backend (Node.js/Express)
- **Authentication**: Secure JWT-based auth with short-lived access tokens (15m) and auto-rotating refresh tokens (7d).
- **Authorization**: Extensible role-based middleware (`admin`, `manager`, `user`).
- **Security**: Password hashing (bcrypt 12 rounds), Rate Limiting, Helmet headers, CORS policies, data sanitization.
- **Robust Error Handling**: Global error catching parsing Mongoose validation errors into structured JSON.
- **Audit Trails**: Built-in tracking of `createdAt`, `updatedAt`, `createdBy`, and `updatedBy` for accountability.

### Frontend (React/Vite)
- **Modern UI/UX**: "Midnight Navy" layout built with Tailwind CSS, featuring subtle glassmorphism, floating label inputs, and smooth micro-animations.
- **Functional Data Grid**: Powerful user directory using `@tanstack/react-table` supporting client-side state combined with server-side pagination/search.
- **Smooth Navigation**: Side-drawer (`SlideOver`) for editing details without losing directory context, ensuring high information density without clutter.
- **Smart Interceptors**: Axios interceptor that automatically attempts to refresh expired tokens in the background transparently.
- **State Management**: Context-API driven global user state, minimizing prop-drilling.

---

## 🛠️ Tech Stack

**Frontend:** React 18, React Router v7, Vite, Tailwind CSS v3, TanStack Table v8, Axios, Lucide React, React Hot Toast.  
**Backend:** Node.js, Express, MongoDB (Mongoose), JSON Web Tokens (jsonwebtoken), Bcryptjs, express-validator.

## 💻 Local Setup Instructions

### Prerequisites
- Node.js (v18 or higher)
- MongoDB (running locally on default port `27017` or an Atlas URI)

### 1. Clone & Install
```bash
git clone <your-repo-link>
cd mern-rbac-auth-system
```

### 2. Backend Setup
```bash
cd server
npm install

# Copy example environment variables
cp .env.example .env
```
Ensure your `MONGODB_URI` in `.env` is correct.

Run the seeder to populate the database with demo users:
```bash
npm run seed
```

Start the backend:
```bash
npm run dev
# Server will run on http://localhost:5000
```

### 3. Frontend Setup
Open a new terminal.
```bash
cd client
npm install

# Copy example environment variables
cp .env.example .env
```
Ensure `VITE_API_URL=http://localhost:5000/api/v1` is set.

Start the frontend:
```bash
npm run dev
# Frontend will run on http://localhost:5173
```

## ☁️ Deployment Strategy

The application is structured to easily deploy on modern PaaS providers:

**Backend (Render / Railway):**
1. Set the Root Directory to `server`.
2. Build Command: `npm install`
3. Start Command: `npm start`
4. Provide environment variables (`MONGODB_URI`, JWT Secrets).

**Frontend (Vercel):**
1. Set the Root Directory to `client`.
2. Build Command is handled automatically by Vercel's Vite preset (`npm run build`).
3. Set `VITE_API_URL` to your deployed backend's URL.
4. Uses `vercel.json` for client-side React Router rewrites.
